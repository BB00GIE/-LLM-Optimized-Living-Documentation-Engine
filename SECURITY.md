# Security Policy

## Supported Versions

We release security updates for the current minor release of the Living Documentation Engine.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of this project seriously. If you discover a security vulnerability or potential threat (such as arbitrary code execution via AST parsing, path traversal in file ingestion, or denial of service in the MCP server runtime), please **do not open a public issue**.

Instead, please report the vulnerability confidentially:

1. **GitHub Security Advisories (Preferred):** Open a private security advisory under the repository's [Security tab](https://github.com/BB00GIE/-LLM-Optimized-Living-Documentation-Engine/security/advisories/new).
2. **Direct Contact:** Email the maintainer at `47788498+BB00GIE@users.noreply.github.com` with the subject `[SECURITY] Living Documentation Engine Vulnerability`.

Please include in your report:
- A description of the vulnerability and its potential impact.
- Clear reproduction steps or proof-of-concept (POC) input files.
- The version/commit of the repository tested and the operating environment.

You will receive an acknowledgment of your report within 48 hours, followed by updates on progress toward a resolution and CVE/credit coordination if applicable.
